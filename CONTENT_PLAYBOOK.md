# Content Playbook

## Tone
Clear, technical, confident, restrained.

## Avoid
- unsupported superlatives
- invented customers
- fake metrics
- generic buzzword stacking
- claims of certification without evidence

## Case-study structure
1. Context
2. Problem
3. Constraints
4. Architecture / approach
5. Implementation
6. Technologies
7. Operational model
8. Outcome
9. Verified metrics, only when available

## Insight structure
1. Clear operating problem
2. Engineering principle
3. Practical tradeoffs
4. Examples
5. Actionable conclusion
