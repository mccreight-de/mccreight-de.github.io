# GitHub Pages

1. Delete or replace the previous HTML files in the repository.
2. Upload all files from this ZIP directly to the repository root.
3. Ensure `index.html` is at the repository root.
4. In GitHub: Settings → Pages.
5. Deploy from `main` and `/ (root)`.
6. Save and wait for publication.

This build does not rely on local CSS, JS, or image folders for rendering.
