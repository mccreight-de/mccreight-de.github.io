This is a significantly expanded enterprise-grade static website for McCreight Labs.

- 15-page corporate information architecture
- Premium dark + light theme system

- Enterprise operations-style hero
- Service architecture, platform, engineering, and case-study pages
- Interactive engineering tabs
- Accessibility page
- Security / trust-center structure
- Careers and insights
- Contact project-intake form (front-end demo only)
- Cookie/local-storage notice
- PWA manifest + lightweight service worker
- SEO meta descriptions + Organization JSON-LD
- `robots.txt` + `sitemap.xml`

- Responsive desktop, tablet, and mobile layouts

## Important integrity rules used in this version

This site intentionally does **not** invent:
- client logos
- customer names
- completed client case studies
- certifications
- compliance audits
- fake metrics
- fake testimonials
- active job openings
- fake email addresses
- fake office addresses

Replace placeholder/example domain references only after the official domain is confirmed.

## Before production launch

1. Replace `https://example.com/` in JSON-LD and `sitemap.xml` with the verified domain.
2. Connect the contact form to a real backend or verified company email workflow.
3. Add final legal text reviewed by qualified counsel.
4. Add verified social links and support/security contact details.
5. Run accessibility, performance, and cross-browser QA.
6. Decide whether Google Fonts should remain externally hosted or be replaced with a local/system font stack.
